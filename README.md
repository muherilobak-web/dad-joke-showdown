Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

The program writes a single dad joke — at most 200 characters, meant to be told out loud — to `/output/entry.txt`. Nothing else is written; the joke is one short two-line exchange with its punchline at the very end.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript is run as-is). The joke is written to `/output/entry.txt` with no trailing newline.
